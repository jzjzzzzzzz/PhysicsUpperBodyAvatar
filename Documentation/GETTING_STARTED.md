# 快速使用指南

本指南用于先运行数字人、观察物理动作，再试用 13 路设备映射。只运行应用不需要安装 Unity 或 Python。

## 1. 打开正确的文件

| 你拿到的内容 | 操作 |
|---|---|
| `PhysicsUpperBodyAvatar-macOS-ARM64.zip` | 解压整个 ZIP，打开根目录 `PhysicsUpperBodyAvatar.app` |
| 本地完整工程 | 打开 `Builds/macOS/PhysicsUpperBodyAvatar.app` |
| 需要修改源码 | Unity Hub 添加工程文件夹，使用 Unity 6000.5.7f1，打开 `Assets/Scenes/UpperBodyLab.unity` 并按 Play |

现成应用适用于 Apple Silicon Mac。首次导入源码时需下载 Unity 包依赖；已构建应用可离线运行。

## 2. 用三分钟检查基本动作

建议先保持阻挡板关闭，依次操作：

| 操作 | 应看到的结果 |
|---|---|
| 点 **Handshake** | 右臂前伸，做短暂握手运动，随后回位 |
| 点 **Wave** | 右臂抬起，手掌在头部附近摆动，随后回位 |
| 点 **Double Thumbs-Up** | 双肘弯曲，四指收拢，双拇指伸出，随后回位 |
| 动作中点 **Return to Idle** | 从当前目标姿态平滑回到放松姿态 |
| 点 **Pause / Resume** | 停止 / 恢复物理步进 |

鼠标在 3D 视口内拖动旋转相机，滚轮缩放。不同动作切换时会先平滑回位；连续点击并不意味着每个请求都排队执行。

**Reset Physics** 是诊断复位，会直接恢复刚体初始位姿，不等同于平滑回位。正常操作优先用 **Return to Idle**。

## 3. 检查是否真正受物理约束

1. 点 **Toggle resistance gate** 打开橙色阻挡板。
2. 点 **Handshake**，观察右手受阻，而目标动作仍在继续。
3. 关闭阻挡板，观察手在电机作用下恢复向目标运动。
4. 点 **Reset test object**，再握手，观察绿色动态方块受到推动。
5. 展开 **Physics Debug** 查看关节角、跟踪误差、接触与实测步频。

界面中的关节反力矩与 PD 估计值不是同一种量，解释见 [物理参数与诊断](PHYSICS.md)。

## 4. 试用手臂 7 路和手掌 6 路

右侧展开 **Servo mapping / 13 channels**，在 **Side** 中选择 Right 或 Left。每次先改一路，便于确认效果：

- **A1–A3**：肩部；**A4**：肘；**A5**：前臂旋转；**A6–A7**：腕部。
- **H1–H4**：分别控制食指、中指、无名指、小指弯曲。
- **H5**：拇指弯曲；**H6**：拇指根部另一方向，暂按外展/对掌近似。

例如，只增加 H1，食指的多个物理指节会联动，其他三指不会跟着握拳。默认输入模板为 0–180°；这是虚拟输入范围，不是已经测得的实物舵机行程。

拖动任一路会进入手动目标模式，停止已有动作轨迹。点 **Release servo control** 或 **Return to Idle** 释放手动控制；点预设动作按钮则切入该动作。释放或播放动作会清除左右两侧手动覆盖。

完整编号、配置方式和实物资料清单见 [硬件映射与标定](HARDWARE_MAPPING.md)。当前应用不向机械手发送指令。

## 5. 从其他程序发送命令

正常启动应用后，在源码工程根目录执行：

```bash
python3 Tools/send_command.py wave --duration 2.5
python3 Tools/send_servo.py --side right
python3 Tools/send_command.py idle
```

Python 仅用于命令行调用；界面操作不需要 Python。协议为本机 TCP，每行一个 JSON，不是 HTTP，详见 [命令接口](COMMAND_API.md)。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 程序打不开或架构不匹配 | 确认使用 Apple Silicon Mac；当前包不是 Windows 或 Intel 原生应用 |
| 命令提示连接被拒绝 | 先正常打开应用，等待场景出现；自测模式不监听 TCP |
| 多开后命令没有控制当前窗口 | 同一端口只能被一个实例占用，保留一个正常实例 |
| 滑块数值变化但手没有到同样的姿态 | 数值是目标，不是实测角；检查障碍、限位、暂停与电机跟踪误差 |
| 手指或关节偏离目标 | 有限力矩、重力和接触会产生误差，不是直接动画覆盖 |
| 相机被转到不方便的位置 | 重新启动应用恢复默认视角；Reset Physics 只复位物理，不重置相机 |
